# Movie Collection

This is a project that Abolfazl and Erfan are building together.

We are in Iran, where internet access is heavily restricted due to the ongoing conflict between Iran and the USA & Israel. Most international services, APIs, and platforms are blocked — including YouTube, Stack Overflow, npm, and many others. Because of this, we've had to find creative workarounds to keep building — for example, using a friend's personal PC as a database server and relying on Iranian mirrors for packages.

## About the Project

A movie collection website where users can browse, search, and manage their movie library.

## Purpose

We are building this project for practice and to learn the technologies involved. In other words — we are learning while coding.

## Tech Stack

- **Frontend:** React + Vite, Tailwind CSS, Vazir font
- **Backend:** Django, Django REST Framework
- **Database:** PostgreSQL
- **Version Control:** Git + GitHub
